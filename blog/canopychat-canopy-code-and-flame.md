# CanopyChat, Canopy Code and Flame: What Each One Does

**Canopy is a small family of AI tools: CanopyChat is a private AI chat app with Agents and image creation, Canopy Code is a coding agent for your terminal, and Flame is an agent that keeps working on its own cloud computer.** They are separate products that connect to the same Canopy account.

## CanopyChat: private AI chat on your devices

CanopyChat is the chat app, for iPhone, Android, Mac, Windows and Linux. On a computer it starts with Canopy Lite, a model that runs on your machine, and needs no account. [Plus](https://canopychat.app/plans) adds using your computer from your phone and cloud models that step in for bigger jobs. [Download CanopyChat](https://canopychat.app/).

## Canopy Code: a coding agent for your terminal

[Canopy Code](https://canopychat.app/canopy-code) is for developers. You run it in a project folder and it reads your code, edits files and runs commands, with the model you choose: ChatGPT, Claude, an API key or a local model. It runs on macOS (Apple silicon), Linux and Windows, has a VS Code extension, and can be followed and steered from the CanopyChat app on your iPhone. Read [the latest release notes](https://canopychat.app/blog/canopy-code-terminal-coding-agent).

## Flame: an agent with a house in the clouds

[Flame](https://canopychat.app/flame) is the AI agent inside CanopyChat. Its own private cloud computer keeps working after you close your laptop, and you check in from your phone. It is invite only for now, and you can join the waitlist on the Flame page.

## Agents: AI that does the work on your computer

The Agents tab in the CanopyChat desktop app is for longer jobs. Give it a task and it works through your files and tools on your own computer, with approval prompts before it changes anything. It can use your installed Canopy Code, so the models and logins you already set up carry over, and you can follow along from your phone.

## Images: create pictures from a chat

Type `/image` and describe what you want. On a computer that can run the image model, it runs there and stays private, with no cloud service involved. Agents can also make images as part of a task.

## Which one should you start with?

- Want a private AI chat? Start with [CanopyChat](https://canopychat.app/).
- Write code and live in a terminal? Try [Canopy Code](https://canopychat.app/canopy-code).
- Want an assistant that works on your computer? Open the Agents tab in [CanopyChat](https://canopychat.app/).
- Want an agent that works while you are away? Join the [Flame waitlist](https://canopychat.app/flame).

New to the idea? Start with [what an AI coding agent is](https://canopychat.app/blog/what-is-an-ai-coding-agent) or [how local AI models work](https://canopychat.app/blog/run-ai-models-locally).
