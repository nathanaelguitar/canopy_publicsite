CanopyChat, Canopy Code and Flame: What Each One Does

Canopy is a small family of AI tools: CanopyChat is a private AI chat app, Canopy Code is a coding agent for your terminal, and Flame is an agent that keeps working on its own cloud computer. They are separate products that connect to the same Canopy account.

CanopyChat: private AI chat on your devices

CanopyChat is the chat app, for iPhone, Android, Mac, Windows and Linux. On a computer it starts with Canopy Lite, a model that runs on your machine, and needs no account. Plus adds using your computer from your phone and cloud models that step in for bigger jobs. Download CanopyChat.

Canopy Code: a coding agent for your terminal

Canopy Code is for developers. You run it in a project folder and it reads your code, edits files and runs commands, with the model you choose: ChatGPT, Claude, an API key or a local model. It runs on macOS (Apple silicon), Linux and Windows, has a VS Code extension, and can be followed and steered from the CanopyChat app on your iPhone. Read the latest release notes.

Flame: an agent with a house in the clouds

Flame is the AI agent inside CanopyChat. Its own private cloud computer keeps working after you close your laptop, and you check in from your phone. It is invite only for now, and you can join the waitlist on the Flame page.

Which one should you start with?

  • Want a private AI chat? Start with CanopyChat.
  • Write code and live in a terminal? Try Canopy Code.
  • Want an agent that works while you are away? Join the Flame waitlist.

New to the idea? Start with what an AI coding agent is or how local AI models work.
