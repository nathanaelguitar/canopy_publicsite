For developers

Install Canopy Code

Comfortable in a terminal? Canopy Code is the coding agent behind CanopyChat. Free to use with ChatGPT, Claude or your own models, and you can drive it from your phone with remote control.

$ brew install nathanaelguitar/canopy/canopy-code
$ canopy
  • Paste it into Terminal on an Apple silicon Mac. Linux and Windows are coming soon.
  • Need Homebrew first? Get it at brew.sh.
  • Using Claude? Install Claude Code too (brew install --cask claude-code), then choose Sign in with Anthropic in /auth.
  • Want remote control from your phone? Create a Canopy account, then link your computer.
